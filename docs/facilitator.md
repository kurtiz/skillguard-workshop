# Facilitating the laptop activity

Topic: **Guarding the Next Generation of AI: Securing Skill Capabilities with SkillGuard**.

Share this repo URL before the session so participants can clone and install before
arriving. Ask people to pair up and share a working machine. Installation needs
internet unless you distribute the exact pinned platform archives in advance.

For a 30-minute session with on-site installation:

| Minutes | Activity |
|---|---|
| 0–3 | Scholarship assistant story and definition of a skill |
| 3–8 | Clone and install; demonstrate checksum verification |
| 8–11 | One presenter scan; explain findings, criticality and coverage |
| 11–19 | Pair challenge in WORKSHOP.md |
| 19–24 | Funkwiz join and four questions |
| 24–26 | Scan / assess / enforce takeaway |
| 26–30 | Questions |

If participants installed beforehand, use the five minutes for a short action
assessment demonstration or extra discussion. Keep the detailed reference-gate
simulation in the presenter materials; it is not required in this participant repo.

People should not activate the injected fixture as an agent skill. The examples are
text to inspect and scan. No private documents or credentials are needed.

After installation, participants use actual CLI commands; there is no Python demo
runner to explain. Take two short responses after the challenge: one repair and one
limit of the scan. A passing scan is evidence, not execution permission.

The presenter supplies the Funkwiz lobby link/code separately. Quiz answers and
private presenter notes are not part of this repo.
