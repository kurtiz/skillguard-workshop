# Teaching fixtures

Open these files as text or scan them with SkillGuard. They are examples, not skills
to activate in your coding agent.

- `clean/SKILL.md`: the legitimate scholarship-summary task.
- `injected/SKILL.md`: the same task plus a hidden HTML comment that tries to override
  instructions and hide behavior. Critical findings and a failed scan are expected.
- `hidden/SKILL.md`: includes an intentional U+200B zero-width space; inspect its warning.

Make repairs in `practice/SKILL.md` as explained in the workshop. Leave these fixtures
unchanged so everyone compares the same evidence.
